# Instrucciones del proyecto

## Entorno y comandos

- En Windows, preferir `cmd.exe` para ejecutar comandos. Usar PowerShell solo si `cmd.exe` no está disponible.
- Antes de modificar el proyecto, inspeccionar su estado y conservar los diseños y archivos existentes.
- Actualizar documentación únicamente con hechos comprobados.

## Tecnología y arquitectura

- C#, .NET Framework, Windows Forms y SQL Server.
- Organizar la solución por capas: Entidad, Datos, Negocio y Presentación.
- Aplicar POO básica, consultas parametrizadas, manejo `try-catch` y comentarios didácticos.
- No crear soluciones ni formularios hasta que el estudiante lo autorice y se haya confirmado la estructura real.

## Secuencia

- No avanzar a SQL Server hasta que el estudiante confirme el árbol real.
- Mantener Login y roles para el final.
- Trabajar Git/GitHub después de los CRUD y antes de Login.
- Los documentos 02 al 10 requieren autorización antes de desarrollarse. Respetar también cualquier bloqueo más específico registrado en `ESTADO_DOCUMENTOS.md`.
- Al terminar cada paso, informar lo realizado y preguntar si se puede continuar.
